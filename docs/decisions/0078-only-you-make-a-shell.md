# Only a press makes a shell

- **Date:** 2026-10-16
- **Area:** [The `terminal` type](../architecture/panels.md#the-terminal-type)

## Decision

Showing the panel or switching project makes no tab; only you make a shell.

## Why

Making one by itself filled All with a shell for every project you had looked at.

## Turned down

- Making a shell by itself wherever there was none, as at first on 2026-10-16: it filled All with a shell for every project you had looked at, and was taken back the same day.
