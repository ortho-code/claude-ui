# A code block has no rule down its side

- **Date:** 2026-09-29
- **Area:** [What it looks like](../architecture/history.md#what-it-looks-like)

## Decision

A code block is a panel of its own with no rule down its side; a quote keeps the rule.

## Turned down

- A rule down a block's side, as at first: it is how a quote is drawn, and a block read as a quote.
