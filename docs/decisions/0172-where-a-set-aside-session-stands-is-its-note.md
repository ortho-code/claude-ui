# Where a set-aside session stands is its note

- **Date:** 2026-11-05
- **Area:** [Status cues](../architecture/status-cues.md#status-cues)

## Decision

Where a set-aside session stands is the session's note, not a line of the mark's own.

## Why

The mark goes the moment its day comes, so a line kept on it would be gone exactly when you come back to read it.
The note stays, through Clear set aside, a prompt there and the day coming, to be read when the session is picked up.
Notes are used without setting aside too, so the note could not become the mark's line without losing those.

## Turned down

- A line of the mark's own: a second text per session that goes when it is wanted.
- Carrying the line into the reminder's reason: a third place for it.
