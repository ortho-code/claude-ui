# The leave button's setting is named for the leave

- **Date:** 2026-11-03
- **Area:** [Tab lifecycle: a tab can exist without a process](../architecture/terminal.md#tab-lifecycle-a-tab-can-exist-without-a-process)

## Decision

The setting's key names the button for what it does, a leave (`leaveButton`), and not for the tab.

## Why

The strip draws the button too.
