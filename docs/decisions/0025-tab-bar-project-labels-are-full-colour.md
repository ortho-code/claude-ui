# The tab bar's project labels are in full text colour

- **Date:** 2026-09-28
- **Area:** [A session whose folder is gone](../architecture/terminal.md#a-session-whose-folder-is-gone)

## Decision

The tab bar's project labels are in full text colour like the headings, and a group's label under its project is told apart by its rail and its lighter weight instead.

## Why

A muted name only says something beside names that are not muted.
The project labels used to be muted themselves.
