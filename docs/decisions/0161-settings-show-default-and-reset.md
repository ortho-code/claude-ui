# Settings shows the default and a Reset under a changed setting

- **Date:** 2026-11-04
- **Area:** [The config folder](../architecture/config.md#the-config-folder)

## Decision

Under every setting whose value in force differs from the app's default, or whose value in the file is not used, Settings says the default and offers a Reset.
It was design decision 40 of 2026-11-04, and was built 2026-11-08.
