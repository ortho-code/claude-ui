# Hovering a list link shows only what the type says

- **Date:** 2026-10-30
- **Area:** [Types from the config folder](../architecture/panels.md#types-from-the-config-folder)

## Decision

Hovering a link in a list row shows only what the type says; whether a row shows where a link goes is the type's choice, as everything a press does is.

## Turned down

- The app always adding where the link goes, as until 2026-10-30, since a shared type's links were taken to be somebody else's.
