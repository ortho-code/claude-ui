# The tab bar orders projects in the order you set

- **Date:** 2026-09-22
- **Area:** [Traps worth knowing](../architecture/ui-conventions.md#traps-worth-knowing)

## Decision

The tab bar puts projects in the order you set, as the session list does.

## Turned down

- Ordering by whichever project the bar met a tab for first, as it used to: emergent rather than chosen, and it moved on its own, closing a project's last tab and opening another sending that project to the end.
