# The project scope holds in the finished view too

- **Date:** 2026-08-27
- **Area:** [UI conventions](../architecture/ui-conventions.md#ui-conventions)

## Decision

The finished view honours the project selected in the switcher, as every other surface does.

## Why

Selecting a project in the switcher is a statement about what you are looking at, so every surface honours it.

## Turned down

- Leaving the finished view exempt from the project scope, as it used to be.
