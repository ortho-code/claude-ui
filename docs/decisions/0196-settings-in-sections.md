# Settings is in sections

- **Date:** 2026-11-08
- **Area:** [The config folder](../architecture/panels.md#the-config-folder)

## Decision

Settings is in sections: General, Sessions, Appearance, Version control and Logs, a vertical tab list beside the one on show.
Every section sits in one box sized by the window alone, up to a cap and down to a floor.

## Why

Switching sections never moves Save under the pointer.
