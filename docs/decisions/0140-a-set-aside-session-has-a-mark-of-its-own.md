# A set-aside session has a mark of its own, beside the dot

- **Date:** 2026-10-29
- **Area:** [Status cues](../architecture/status-cues.md#status-cues)

## Decision

A session set aside carries a mark of its own, beside the dot rather than on it (`setAside`).

## Why

"Needs you" is for what really needs looking at, and a session set aside needs nothing yet.
