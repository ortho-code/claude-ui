# A panel's row that names a session has one kebab

- **Date:** 2026-11-08
- **Area:** [A session's menu holds everything about it](../architecture/terminal.md#a-sessions-menu-holds-everything-about-it)

## Decision

A panel's row's own actions beyond its buttons sit under the session menu's header, before the session's items, so the row has one ⋮.

## Why

Two kebabs on one row look alike and are told apart only by trying.

## Turned down

- A kebab for the row's own actions beside the session's: two kebabs on one row look alike and are told apart only by trying.
