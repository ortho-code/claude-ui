# The compact list row is a shape of its own

- **Date:** 2026-10-13
- **Area:** [Sizes and shapes](../architecture/ui-conventions.md#sizes-and-shapes)

## Decision

The compact list row is a shape of its own, though it resembles the menu row: it keeps the list row's builder, hover and controls and only drops the card.

## Why

A menu row is a choice in a menu, and a compact row is an item in a list.
