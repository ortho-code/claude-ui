# The app names the folder a panel looks in

- **Date:** 2026-10-26
- **Area:** [Where a panel runs: the `cwd` option](../architecture/panels.md#where-a-panel-runs-the-cwd-option)

## Decision

The app names the folder a panel looks in, beside its title, rather than each type.

## Why

Where a panel looks is the app's decision.

## Turned down

- A note a type prints, or a heading it sets: only the types that print one would say it, and a type you were sent could name a folder it is not in.
